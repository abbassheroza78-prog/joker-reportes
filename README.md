# جوكر التقارير الجامعية

مشروع Flutter أولي لتطبيق Android باسم **جوكر التقارير**.

## الهدف
تطبيق عربي لإنشاء التقارير الجامعية، مع اختيار شعار الجامعة اختياريًا.

## تشغيل وبناء APK
على جهاز/بيئة فيها Flutter وAndroid SDK:
```bash
flutter pub get
flutter build apk --release
```

ملف APK الناتج عادةً:
`build/app/outputs/flutter-apk/app-release.apk`

> هذا المشروع مصدر التطبيق وليس APK جاهزًا. إخراج APK يتطلب بيئة Android/Flutter للبناء.
